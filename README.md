# 双高雷达 · 高血压高血脂前沿技术与治疗方案

高血压 + 高血脂前沿技术展示版：展示双高领域的前沿技术与目前的治疗方案，
参考 OncoRadar 全球抗癌药研发情报系统的六大模块骨架改写。
用 **Vite + React 18 + Ant Design 5 + recharts** 开发，亮色、日光风格，手机端可用。

> 方向说明：本站**不做个人记录**。此前第一期（个人记录版）的血压/血脂/体重/用药录入、
> “我的数据”页、localStorage 存储与示例数据已全部删除，不再提供。

## 新导航（8 页）

- **首页概览**：双高领域全局概览——收录药物/技术数量、试验阶段分布、技术路线分布、
  适应症分布、近期重大事件数量；明确写数据口径与更新时间（截至 2026-11）。
- **前沿技术雷达**：重大突破与研发事件，按时间倒序，支持按事件类型/技术类型筛选；
  每条写中文摘要、事件类型（试验推进、结果公布、获批、失败/未达终点、指南更新）与原始出处。
- **治疗方案**：目前的治疗方案总览，按指南分层——降压五类经典药物与联合/阶梯治疗；
  降脂分层达标与联合方案；血压目标 < 140/90、家庭血压 < 135/85，
  LDL-C 分层目标（低危 < 3.4、中高危 < 2.6、极高危 < 1.8 且降幅 > 50%、超高危 < 1.4 且降幅 > 50%）。
- **药物资料库**：26 个药物 / 技术档案，按药名、靶点、技术类型检索；每个档案写机制、靶点、
  技术类型、研发/上市阶段、适应症与关键终点，不写个人用药建议。
- **试验追踪**：15 项关键临床试验，含试验名、阶段、适应症、主要终点、状态、结果登记与变更记录；
  临床试验编号只写已核实的三项（BaxHTN NCT06034743、CLEAR Outcomes NCT02993406、
  Lp(a)HORIZON NCT04023552），其余只写试验名与公开来源。
- **医学证据分析**：按终点查证据——收缩压降幅、LDL-C 降幅%、MACE 风险比；
  分清替代终点与硬终点，图表与表格均注明试验名与来源。
- **前沿解读**：18 篇解读，基础、用药、生活方式、误区与前沿解读五类，每篇写明依据来源与版本。
- **正确测压**（附录）：正确测压指南与常见问题，帮助理解家庭血压与诊室血压的区别。

## 数据来源与更新口径

- 数据来源：ClinicalTrials.gov、PubMed、美国 FDA / 欧洲 EMA、中国 NMPA、企业公告、
  AHA / ESC / ACC 学术会议、《中国高血压防治指南（2024 年修订版）》《中国血脂管理指南（2023 年）》。
- 更新时间：截至 2026-11；收录为人工整理的公开情报，不是全球试验数据库的全量统计。
- 特别说明：本站未接入中国 CDE 试验登记数据（反自动化限制），中国在研管线以 NMPA 与企业公告为准；
  历史数据尚未全量回填，当前以近几年关键试验与事件为主。
- 准确性红线：试验结果数字必须标试验名和来源；不确定的写“在研中，尚未公布关键结果”，不编数字；
  不写个人用药建议；全站保留免责声明——本站仅提供公开情报与科普展示，不构成诊疗建议，用药请遵医嘱。
- 药品图片：26 个药物/技术中 25 个配有 Wikimedia Commons 公开图片（小分子为化学结构式，单抗/siRNA
  为产品实物图或机制示意图，示意图已在图注中注明“非本产品实物”）；高血压疫苗暂无合适公开图片，
  用“暂无实物图”占位，不用假图冒充。图片全部外链引用，不存入仓库。
- 来源链接：药物、雷达事件、试验、证据、解读文章与首页来源清单均已加可点击的来源链接（PubMed、
  ClinicalTrials.gov、FDA、EMA、Roche 公告等），上线前已逐个核实可打开；NMPA 官网链接因本环境无法
  核实访问而暂不挂链，只保留文字来源。

## 本地运行

```bash
npm install
npm run dev      # 开发模式，浏览器打开提示的地址
npm run build    # 构建，产物在 dist/
npm run preview  # 本地预览构建产物
```

## 部署（Vercel，当前线上）

- 线上地址：https://shuanggao-leida.vercel.app
- Vercel 接 GitHub 仓库 `chaclee/shuanggao-leida`，main 分支自动部署；
  构建命令 `npm run build`，输出目录 `dist`，框架 Vite。
- 仓库里的 `wrangler.toml` 是给 Cloudflare Pages 用的，Vercel 会忽略，不用删除。
- 以后每次改完，`git push` 到 main 就会自动重新部署。
